# Beautify Yourself & Beyond℠ - Product Requirements Document

## Vision
A comprehensive wellness & community app that helps users beautify themselves from the inside out. Combines personal somatic wellness tools with a supportive community garden where users can share their journey through beautiful flower blooms.

## Brand
- **Brand Owner:** BossLadyLisa℠
- **Tagline:** "This is where you Beautify Yourself on the inside"
- **Motto:** "We'll keep the light on for you."
- **Symbol:** Dragonfly (transformation, lightness)
- **Aesthetic:** Elegant teal/gold/terra with dragonfly & floral motifs

## Core Features

### Personal Sanctuary (Completed ✅)
1. **Home Dashboard** - Beautiful landing with quick access to all tools
2. **Reset Toolkit** - Mood selection → DBT-Somatic reset card + AI-personalized guidance (Claude Sonnet)
3. **Daily Journal** - Grounded thoughts with search & timestamps
4. **143 Life Notes℠** - Quick wisdom capture
5. **Visual Quote Cards** - Affirmation cards for daily inspiration
6. **Boss Mode Planner℠** - Task management with priority levels
7. **Declutter Tools** - Checklist + meditation timer
8. **Daily Affirmations℠** - Streak tracking, personalized library
9. **Feedback** - User voice collection

### Community Garden (Planned)
- Three-tier subscription system with different privacy levels
- Somatic breathing ritual before posting
- Flower visualization system with garden zones
- Community "watering" (support) feature
- Tier-based feature gating

## Tech Stack
- **Frontend:** Expo/React Native with expo-router (Stack Navigation)
- **Backend:** FastAPI + MongoDB
- **AI:** Claude Sonnet 4.6 (via Emergent LLM Key)
- **Auth (Planned):** Emergent Google OAuth + JWT email/password
- **Payments (Planned):** Stripe subscriptions

## Subscription Tiers (Planned)
- **🌱 Sanctuary Seed** (Free): Basic tools + public community blooms
- **🌸 Blossom Circle** ($4.99/mo): Privacy-protected sharing + watering
- **🦋 Sacred Grove** ($9.99/mo): Named blooms + exclusive zones
